## 先看 0.333...

把循环小数写成分数，核心动作只有两个：**移位**，然后**相减**。

设：

```text
x = 0.333...
```

两边同时乘 10，小数点向右移一位：

```text
10x = 3.333...
```

用下面的式子减上面的式子：

```text
10x - x = 3.333... - 0.333...
9x = 3
x = 1/3
```

所以：

```text
0.333... = 1/3
```

看起来像“无限减无限”，其实两条小数尾巴完全一样，相减时正好抵消。

## 两位循环节

再看：

```text
x = 0.363636...
```

循环节是两位，所以乘 100：

```text
100x = 36.363636...
```

相减：

```text
100x - x = 36.363636... - 0.363636...
99x = 36
x = 36/99 = 4/11
```

x.com 上，unconed 把这条规律概括得很直接：N 位循环节，分母就是 N 个 9（[原帖](https://x.com/unconed/status/2025961360752865533)）。所以：

```text
0.333... = 3/9
0.363636... = 36/99
```

也可以先记住几个小例子：

```text
1/9 = 0.111...
1/99 = 0.010101...
1/999 = 0.001001001...
```

分母有几个 9，对应的循环节就有几位。

## 带前缀的循环小数

不是所有循环小数都从小数点后第一位开始循环。比如：

```text
x = 0.1666...
```

这时不能直接乘 10，因为乘 10 后尾巴还在：

```text
10x = 1.666...
100x = 16.666...
```

用 100x 减 10x，把两条 6 的尾巴消掉：

```text
90x = 15
x = 15/90 = 1/6
```

所以：

```text
0.1666... = 1/6
```

处理这类数，先把不循环的前缀移走，再按循环节的长度决定乘多少。循环节有多长，最后就对应几个 9。

## 0.999... 为什么等于 1

用同样的方法：

```text
x = 0.999...
10x = 9.999...
9x = 9
x = 1
```

所以：

```text
0.999... = 1
```

它不是“差一点点到 1”。0.999... 表示 9 无限循环，本身就是 1 的另一种写法。

## 一句话规律

纯循环小数，循环节有 N 位，化成分数时分母就是 N 个 9：

```text
0.\overline{36} = 36/99
```

带前缀的混循环小数，先把前缀移走，再按循环节长度处理：

```text
0.1\overline{6} = 1/6
```

更严格地说，无限小数要用极限定义；这里用“移位相减”，是为了先看清它在做什么。只要两条无限尾巴能对齐，相减就能把无限部分消掉。
