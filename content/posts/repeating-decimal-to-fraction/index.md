## 先看 0.333...

循环小数看起来“写不完”，但它可以变成一个普通分数。

设：

```text
x = 0.333...
```

两边同时乘 10，小数点向右移一位：

```text
10x = 3.333...
```

现在用下面的式子减上面的式子：

```text
10x - x = 3.333... - 0.333...
9x = 3
x = 1/3
```

所以：

```text
0.333... = 1/3
```

看起来像“无限减无限”，但两条小数尾巴完全一样，相减时正好抵消。

## 为什么乘 10 就能消掉尾巴

关键是小数点的位置。

把 `0.333...` 乘 10，相当于把每一位都往左移一位：

```text
0.333...  →  3.333...
```

整数部分变成了 3，小数部分仍然是 `333...`。原来的数和移位后的数，小数部分一模一样，所以相减只剩一个 3。

这不是碰巧。循环节有几位，就乘 10 的几次方，让一个完整的循环节移到整数部分，剩下的尾巴仍然相同。

## 两位循环节

再看：

```text
x = 0.363636...
```

循环节是两位，所以乘 100：

```text
100x = 36.363636...
```

相减：

```text
100x - x = 36.363636... - 0.363636...
99x = 36
x = 36/99 = 4/11
```

x.com 上，unconed 把这条规律概括得很直接：N 位循环节，分母就是 N 个 9（[原帖](https://x.com/unconed/status/2025961360752865533)）。

```text
0.333... = 3/9
0.363636... = 36/99
```

也可以先记住几个小例子：

```text
1/9 = 0.111...
1/99 = 0.010101...
1/999 = 0.001001001...
```

分母有几个 9，对应的循环节就有几位。

## 一般规律

设循环节是 N 位数字，记作 B：

```text
x = 0.BBB...
```

把小数点向右移 N 位：

```text
10^N × x = B + 0.BBB...
```

因为移过去的整数部分正好是 B，剩下的小数部分还是原来的循环小数：

```text
10^N × x = B + x
```

移项：

```text
(10^N - 1) × x = B
x = B / (10^N - 1)
```

这就是“N 位循环节，分母是 N 个 9”的来源。

例如：

```text
0.363636... = 36/(100 - 1) = 36/99 = 4/11
```

分母的 99 不是随便来的，它就是 `100 - 1`。

## 带前缀的循环小数

不是所有循环小数都从小数点后第一位开始循环。比如：

```text
x = 0.1666...
```

这时直接乘 10，尾巴还在：

```text
10x = 1.666...
100x = 16.666...
```

用 100x 减 10x，把两条 6 的尾巴消掉：

```text
90x = 15
x = 15/90 = 1/6
```

所以：

```text
0.1666... = 1/6
```

再看一个更一般的例子：

```text
x = 0.123434...
```

前缀 `12` 有 2 位，循环节 `34` 有 2 位。

先乘 100，把前缀移走：

```text
100x = 12.343434...
```

再乘 10000，把循环节也移走：

```text
10000x = 1234.343434...
```

两式相减：

```text
9900x = 1222
x = 1222/9900 = 611/4950
```

这类数的分母可以记成：**N 个 9，后面再跟 M 个 0**。

- `0.1666...`：循环节 1 位，前缀 1 位，分母是 90。
- `0.123434...`：循环节 2 位，前缀 2 位，分母是 9900。

## 0.999... 为什么等于 1

用同样的方法：

```text
x = 0.999...
10x = 9.999...
9x = 9
x = 1
```

所以：

```text
0.999... = 1
```

它还有一条更直观的验证：

```text
1/3 = 0.333...
3 × 1/3 = 1
3 × 0.333... = 0.999...
```

两边都等于同一个数，所以 `0.999...` 就是 1。

它不是“差一点点到 1”。0.999... 表示 9 无限循环，没有最后一个 9，因此没有一个固定的“差”。

## 更严格地看

移位相减不是数学魔法，它对应无限级数。

以 `0.333...` 为例：

```text
0.333... = 3/10 + 3/100 + 3/1000 + ...
```

这是一个等比数列，首项是 `3/10`，公比是 `1/10`。它的和是：

```text
(3/10) / (1 - 1/10) = 1/3
```

所以代数运算的结果和级数求和一致。

严格来说，循环小数要用极限定义；初中阶段先用“移位相减”理解，结论是一样的。

## 常见错误

- `0.363636...` 用了 9 而不是 99。循环节有两位，分母要有两个 9。
- `0.1666...` 直接写成 `6/9`。前面还有一个不循环的 1，必须先把它移走。
- 把 `0.999...` 当成“比 1 小一点”。它没有最后一位，差不是某个正数。
- 算出分数后忘记约分。`36/99` 还要化成 `4/11`。

记住一句话：**循环节有几位，就乘 10 的几次方；把无限尾巴对齐后减掉，剩下的就是普通分数。**
